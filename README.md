# Приложение для импорта товаров из CSV

Учебное приложение на ASP.NET Core MVC (.NET 10) для производственной практики.

## Функционал
- Загрузка товаров из CSV-файла через веб-интерфейс.
- Валидация данных:
    - Проверка на пустые обязательные поля (SKU, Название).
    - Проверка форматов и отрицательных значений (Цена, Количество).
    - Проверка уникальности SKU (в файле и в хранилище).
    - Поддержка кириллицы (UTF-8).
- Отображение списка импортированных товаров.
- Хранение данных в оперативной памяти (InMemory).
- Современный интерфейс на Bootstrap.

## Требования к CSV файлу
- Разделитель: точка с запятой (`;`).
- Кодировка: UTF-8.
- Обязательные столбцы: `Sku;Name;Price;Quantity`.

## Запуск проекта
1. Убедитесь, что у вас установлен .NET 10 SDK.
2. Склонируйте или скачайте проект.
3. Откройте терминал в папке проекта.
4. Выполните команду:
   ```bash
   dotnet run
   ```
5. Перейдите по адресу, указанному в терминале (обычно `http://localhost:5000` или `https://localhost:5001`).

## Тестирование
Для проверки работы можно использовать файл `sample_products.csv`, который находится в корне проекта. Он содержит как корректные данные, так и строки с ошибками для демонстрации валидации.

## Структура проекта
- `Models/`: сущности `Product`, `ImportResult`, `ImportError`.
- `Services/`: бизнес-логика импорта и репозиторий для хранения данных.
- `Controllers/`: `ProductController` для обработки веб-запросов.
- `Views/`: представления для списка товаров и формы импорта.
